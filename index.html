MCP & JSON-RPC API

Dựng video tự động bằng AI Agent & Code

Chill Studio đi kèm máy chủ JSON-RPC và giao thức MCP, cho phép các AI Agent tự động cắt video, chèn phụ đề và xuất file hàng loạt. 

# Khởi chạy Chill Studio ở chế độ máy chủ hoặc dòng lệnh (CLI)
chillstudio --version

# Hoặc gọi trực tiếp qua JSON-RPC / MCP để cắt ghép & tạo phụ đề tự động
{"jsonrpc": "2.0", "id": 1, "method": "project.open", "params": {"path": "vlog.chillstudio"}}
{"jsonrpc": "2.0", "id": 2, "method": "speech.transcribe", "params": {"model": "whisper-small", "language": "vi"}}
{"jsonrpc": "2.0", "id": 3, "method": "export.start", "params": {"output": "final_4k.mp4", "preset": "h264_4k60"}}
